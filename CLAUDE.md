# Project Instructions

This repository is an original recreation of the supplied PlayPower Labs Airbnb-listing reference.

## Priorities
1. Preserve rendered-reference fidelity before adding abstractions.
2. Do not invent UI or workflows not present in the assignment.
3. Keep the three required experiences complete: Listing, Photo Tour, Lightbox.
4. Maintain keyboard and screen-reader accessibility.
5. Keep TypeScript strict and dependencies minimal.
6. Prefer focused, reusable components.
7. Verify key geometry and interactions with Playwright.
8. Never copy implementation/source code from the reference application.
9. Do not bundle or redistribute proprietary font binaries.
10. Keep final submission artifacts clean; reference-capture tooling is development-only.

## Completion checks
- `npm run lint`
- `npm run build`
- `npm test`
- manual 1440×900 visual comparison
- keyboard-only Photo Tour/Lightbox pass
- reduced-motion check
